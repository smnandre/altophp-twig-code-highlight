# Twig Code Highlight

Highlight source in Twig using a block tag or a filter. The extension delegates
parsing and HTML generation to Code Highlight and integrates with Twig autoescaping.

## Introduction

- [Installation](installation.md)
- [Getting started](getting-started.md): register Twig and render actual highlighted HTML.

## Usage

- [Tag/filter](usage.md): literal or dynamic source and per-call options.
- [Configuration](configuration.md): defaults, themes, and runtime wiring.
