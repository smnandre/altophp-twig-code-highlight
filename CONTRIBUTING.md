# Contributing

Use PHP 8.4 or later, install development dependencies with `composer install`,
and run `composer qa` before submitting a focused pull request. Use
`composer cs:fix` to apply style fixes. Add Twig integration tests when changing
tag parsing, runtime registration, option handling, or escaping.

Discuss changes in the [issue tracker](https://github.com/altophp/twig-code-highlight/issues).
